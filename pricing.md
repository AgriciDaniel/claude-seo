# Pricing — Claude SEO

> Free, open-source AI SEO audit tool for [Claude Code](https://claude.com/product/claude-code).
> Site: [https://claude-seo.md](https://claude-seo.md)
> Repository: [https://github.com/AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)

Claude SEO has **no paid Claude SEO tier**. The skill is MIT licensed and runs locally.

## Free (MIT)

- **Price:** $0 forever
- **Limits:** No per-site pricing, no usage caps from Claude SEO, no Claude SEO tracking
- **Includes:** 26 sub-skills, 19 specialist agents, core `/seo` commands, `/seo setup` and `/seo doctor`
- **Requirements:** Claude Code 1.0.33+, Python 3.11–3.14, Git
- **Billing note:** Full audits use your Claude Code plan tokens (Opus + Sonnet agents). That is Anthropic usage, not a Claude SEO fee.

## Optional extensions (bring your own account)

These are optional. Claude SEO works without them. Each third party bills you separately if you connect credentials.

| Extension | Price model | What it adds |
|-----------|-------------|--------------|
| DataForSEO | Pay-as-you-go API | Live SERP, keywords, backlinks, AI visibility |
| Firecrawl | Provider plan | Full-site crawl with JS rendering |
| Banana / Gemini image gen | Provider plan | OG images, heroes, SEO assets |
| Ahrefs MCP | Ahrefs subscription | Backlink and keyword data |
| SE Ranking | SE Ranking plan | Share of voice in AI answers |
| Profound | Profound plan | AI citation monitoring |
| Bing Webmaster | Free with Bing account | Bing data + IndexNow |
| Unlighthouse | Free / self-hosted | Site-wide Lighthouse |
| Matomo | Self-hosted or Matomo Cloud | Analytics alternative to GA4 |
| Google APIs (GSC, PSI, CrUX, GA4, Indexing) | Google Cloud quotas | Field data and reporting |
